unipaste

Formateador universal de streams HTML y texto enriquecido para el portapapeles
Activo

Parser en C99 que agarra el HTML enredado del portapapeles y lo convierte en Markdown limpiecito. Te arma tablas en cajas ASCII al pelo, parsea listas de tareas, decodifica entidades HTML y le quita los headers raros de Windows sin depender de navegadores ni librerías pesadas.

C99 PARSERS MARKDOWN SISTEMAS ZERO-DEP

Daemon y bridge universal de portapapeles potenciado por unipaste
Activo

Daemon para Windows y Linux que se queda escuchando el portapapeles en segundo plano. Cuando copias cualquier vaina de Slack, Teams o el navegador, le pasa el HTML a unipaste y te actualiza el portapapeles de texto plano al tiro con Markdown listo para pegar.
