gitcrawl ↗

Crawler y archivador web direccionable por contenido sobre repositorios Git
Activo

CLI en C99 que rastrea sitios web y guarda snapshots históricos en Markdown directamente dentro de repositorios Git (.git/objects). Se salta el working tree escribiendo objetos en memoria, usa compresión delta nativa para ahorrar gigabytes y te permite auditar cambios con git diff y git log sin bases de datos.

C99 GIT PLUMBING CRAWLERS POSIX ZERO-DEP

approx ↗

Filtro y ranker difuso para streams POSIX (no interactivo)
Activo

CLI ultraligera en C99 con cero dependencias para filtrar y ordenar texto en streams usando coincidencia difusa. Usa memoria O(M) con programación dinámica. La armé para meterla en scripts, pipelines UNIX y microcontroladores donde las TUIs interactivas como fzf no dan la talla.

C99 POSIX ALGORITMOS EMBEBIDOS / IOT ZERO-DEP

unipaste ↗

Formateador universal de streams HTML y texto enriquecido para el portapapeles
Activo

Parser en C99 que agarra el HTML enredado del portapapeles y lo convierte en Markdown limpiecito. Te arma tablas en cajas ASCII al pelo, parsea listas de tareas, decodifica entidades HTML y le quita los headers raros de Windows sin depender de navegadores ni librerías pesadas.

C99 PARSERS MARKDOWN SISTEMAS ZERO-DEP

clipbridge ↗

Daemon y bridge universal de portapapeles potenciado por unipaste
Activo

Daemon para Windows y Linux que se queda escuchando el portapapeles en segundo plano. Cuando copias cualquier vaina de Slack, Teams o el navegador, le pasa el HTML a unipaste y te actualiza el portapapeles de texto plano al tiro con Markdown listo para pegar.
