beam ↗

CLI de intercambio efímero de archivos y streaming de video local-first en C99
Activo

CLI en C99 que comparte archivos locales mediante enlaces HTTP efímeros con expiración automática. Soporta peticiones HTTP Range (206 Partial Content) para scrubbing instantáneo en reproductores de video nativos (Chrome, Safari, iOS), zero-copy con sendfile(), túneles públicos rápidos de Cloudflare (-p), códigos QR en consola Unicode y piping directo desde autodub.

C99 POSIX HTTP / STREAMING VIDEO TUNNELING CLI ZERO-DEP

autodub ↗

Pipeline CLI de doblaje de video local y síntesis de voz en CPU
Activo

Herramienta de línea de comandos que descarga videos con yt-dlp, transcribe el audio en CPU con faster-whisper (cuantización int8), traduce los segmentos y sintetiza la voz doblada con Piper TTS o Edge-TTS. Ajusta la velocidad por segmento con atempo para cuadrar con el video original sin desfase temporal y atenúa el audio de fondo para no perder la música ni los efectos.

PYTHON WHISPER TTS FFMPEG AUDIO PIPELINE CLI

dshuf ↗

Shuffler balanceado multiclave en C99/POSIX con soporte para streaming
Activo

Herramienta CLI y librería de cabecera única en C99/POSIX suckless que espacia elementos con atributos compartidos (artista, álbum, género) usando una heurística voraz de penalización en ventana para evitar repeticiones seguidas en playlists y pipelines UNIX. Soporta streaming infinito con memoria estrictamente acotada O(W) y bindings sin dependencias para C++, Python y TypeScript/WASM.

C99 POSIX SUCKLESS ALGORITMOS PIPELINES UNIX ZERO-DEP

gitcrawl ↗

Crawler y archivador web direccionable por contenido sobre repositorios Git
Activo

CLI en C99 que rastrea sitios web y guarda snapshots históricos en Markdown directo en repositorios Git (.git/objects). Se salta el working tree escribiendo objetos en memoria a millón, usa compresión delta nativa para ahorrar gigas y te deja auditar cualquier cambio con git diff y git log sin meter bases de datos.

C99 GIT PLUMBING CRAWLERS POSIX ZERO-DEP

approx ↗

Filtro y ranker difuso para streams POSIX (no interactivo)
Activo

CLI ultraligera en C99 con cero dependencias para filtrar y ordenar texto en streams usando coincidencia difusa. Usa memoria O(M) con programación dinámica. La armé para meterla en scripts, pipelines UNIX y microcontroladores donde las TUIs interactivas como fzf no dan la talla.

unipaste ↗

Formateador universal de streams HTML y texto enriquecido para el portapapeles
Activo

Parser en C99 que agarra el HTML enredado del portapapeles y lo convierte en Markdown limpiecito. Te arma tablas en cajas ASCII al pelo, parsea listas de tareas, decodifica entidades HTML y le quita los headers raros de Windows sin depender de navegadores ni librerías pesadas.

C99 PARSERS MARKDOWN SISTEMAS ZERO-DEP

clipbridge ↗

Daemon y bridge universal de portapapeles potenciado por unipaste
Activo

Daemon para Windows y Linux que se queda escuchando el portapapeles en segundo plano. Cuando copias cualquier vaina de Slack, Teams o el navegador, le pasa el HTML a unipaste y te actualiza el portapapeles de texto plano al tiro con Markdown listo para pegar.
