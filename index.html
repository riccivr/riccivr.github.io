approx

Filtro y clasificador de streams difusos POSIX no interactivo
Enfoque Activo

Utilidad CLI ligera en C99 con cero dependencias que puntúa, filtra y clasifica texto en streaming usando distancia aproximada normalizada de cadenas. Coincidencia por programación dinámica O(M) optimizada en memoria para tuberías (pipelines) UNIX automatizadas, scripts de shell y sistemas embebidos / IoT con recursos limitados donde las TUIs interactivas no dan la talla.

C99 POSIX ALGORITMOS EMBEBIDOS / IOT CERO-DEP

unipaste

Formateador universal de streams HTML y texto enriquecido para el portapapeles
Enfoque Activo

Parser de streams en C99 / POSIX sin dependencias que convierte cargas enredadas del portapapeles y HTML enriquecido en Markdown estructurado, tablas ASCII/Unicode en cajas, bloques de código y listas de tareas jerárquicas. Incluye decodificación exhaustiva de entidades HTML, manejo de cabeceras CF_HTML de Windows y arquitectura de plugins modulares en tiempo de compilación para saneamiento con cero sobrecarga.

C99 PARSERS MARKDOWN SISTEMAS CERO-DEP
[G] Ver Repositorio riccivr/unipaste

clipbridge

Demonio y puente universal para el portapapeles potenciado por unipaste
Enfoque Activo

Demonio multiplataforma para escuchar eventos del portapapeles nativo del sistema operativo (APIs de secuencia Win32 / POSIX) integrado directamente con el motor de formateo unipaste. Intercepta texto enriquecido copiado desde Slack, Teams, navegadores o apps de Electron y actualiza la ranura de texto plano al instante con cero costo de sondeo (polling).

C99 WIN32 POSIX DEMONIO INTEGRACIÓN
